Primary original project

AWS Serverless Metadata Workflow

S3 object-created events invoke a Python Lambda function. The function reads object headers, normalizes metadata, and uses a conditional DynamoDB write to make repeated delivery safe. Failed asynchronous invocations can move to an encrypted SQS queue for controlled recovery.

What I deliberately did not use to pad this page

Forks are not presented as original AWS work

The public `cloudlens` repository is a fork of an existing project. It may be useful for exploration, but it is not listed here as proof that I designed or authored the underlying cloud console tool.

Design references are not treated as deployed infrastructure

Car Match documentation contains AWS and Cognito design ideas, but the current deployed Car Match implementation is not presented as an AWS production project. A plan is not the same thing as running proof.
