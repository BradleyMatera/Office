The project in one minute

A file upload automatically becomes a searchable metadata record

A file is uploaded to Amazon S3. The upload event invokes AWS Lambda. The function reads the object headers, normalizes the useful metadata, and stores a structured record in DynamoDB. The original project also included a static frontend and a measurable cloud-cost model.

01

Upload

A file enters an S3 bucket and produces an object-created event.

02

Extract

Lambda reads object metadata without downloading the full file body.

03

Store

DynamoDB receives a normalized record that can be inspected and queried later.

How it works

The full workflow without unnecessary complexity

Each service has one clear responsibility. That makes the system easier to explain, troubleshoot, test, and operate than a larger always-on application would be.

Amazon S3

Receives uploaded files, stores object versions, and emits object-created notifications.

AWS Lambda

Validates the event, decodes the object key, reads headers, and normalizes the record.

Amazon DynamoDB

Stores one deterministic record per object identity using a conditional write.
